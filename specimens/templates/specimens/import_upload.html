Column guide
  • One row per specimen. Required: {% for c in required %}{{ c }}{% if not forloop.last %}, {% endif %}{% endfor %}.
  • row_key is your own reference for the row (up to 40 characters, unique in the file). The system assigns the specimen ID.
  • Types, containers, units, participants and collections are given by their catalogue codes. Unit codes keep their case (mL).
  • quantity is an exact decimal in that unit. Times are ISO 8601, for example 2026-11-01T09:30:00-05:00; a time without an offset is read in repository time.
  • participant_code is a coded identifier only, never a name or record number.
  • box_code and position_label together store the specimen in a free position; leave both blank to register it unplaced.
  • baseline_thaws is the number of thaws before registration; leave it blank if unknown.
