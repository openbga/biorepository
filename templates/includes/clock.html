{% comment %} A time-out-of-storage clock (docs/ui-standards.md section 8): the stopwatch icon and the duration, warm while it runs. The only warm element: warm means "out of the cold, time is counting". Rendered by the {% clock %} tag ({% load ui %}). Parameters: value the duration as text, already formatted (e.g. timeout.total|duration) running truthy while the period is open (data-state="running"); otherwise "stopped" long truthy when the period is long enough to need attention (data-long); the threshold is the caller's label optional visually hidden words before the value (default "Time out of storage") Usage: {% clock value=timeout.total|duration running=timeout.open %} {% endcomment %} {% load ui %}{% icon name="stopwatch" %}{% firstof label "Time out of storage" %}{% if running %}, running{% endif %}: {{ value }}
